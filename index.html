TikTok

Machine Learning Engineer Intern
Jun 2026 – Sep 2026Beijing, China

Recommendation ranking, negative-feedback modeling and an agentic tuning framework. Independently delivered 5 launch requests, all shipped to production.

  • Dislike model iteration. Added a pointwise skip objective as auxiliary training on top of the existing pairwise Dislike objective for the user negative-feedback model, improving SD and negative-feedback metrics. Deployed to production.
  • Ranking fusion optimization. Redesigned the Dislike score in both the fine-ranking and blending stages, replacing the fractional formulation with a sigmoid-based transform for better controllability, and introduced a user-level Dislike coefficient that suppresses more strongly for users with higher Dislike propensity. Both iterations improved negative-feedback metrics and launched.
  • Recommendation system agent. Designed and built an agentic recommendation optimization framework on my own: an Intent Agent based on the ACE framework that uses supervised LLM-as-a-Judge to infer unified user intent from long-term profiles and recent behavior, plus a Multi-Objective Tuning Agent that generates personalized recommendation parameters conditioned on that intent. A Dislike strategy produced by the agent shipped to production.
  • Multi-queue ranking optimization. Simplified and standardized the multi-queue PK ranking pipeline by unifying ranking logic and PK mechanisms across content genres, with gains in LT, HLT and SD. Deployed to production.
  • Recommendation strategy optimization. Removed the short-story queue from the blending pipeline to cut exposure to low-quality content, improving negative-feedback metrics. Deployed to production.

OZ Intelligence

Software Engineer Intern
Jun 2025 – Dec 2025Beijing, China

Real-time physiological monitoring and an adaptive AI biofeedback agent, validated in a 48-participant study and published at CHI 2026.

  • Built a real-time physiological monitoring system as a WeChat mini-program in JavaScript, streaming BLE data at 25 Hz and computing HR, HRV and respiration rate with under 500 ms display latency.
  • Developed a hybrid client–server architecture with a Flask REST API and WebSockets for bidirectional communication, with frontend–backend arbitration logic to keep metrics consistent across compute sources.
  • Implemented an adaptive breathing-guidance algorithm that adjusts the respiration cycle from real-time HRV feedback. In a 48-participant user study it improved HRV by 26.8 ms and extended high-HRV duration by 76.6% over baseline.
  • Designed a state-aware, proactive AI agent for real-time biofeedback that combines personalized HRV baselines, trend-aware decision logic and LLM-guided strategy selection to drive adaptive breathing interventions in a closed loop.
  • Published this work as first author at ACM CHI 2026.
